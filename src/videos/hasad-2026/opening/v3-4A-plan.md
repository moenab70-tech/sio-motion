# v3 · Shot 4A: the hero alone (stop-motion test)

Goal: the main hero alone (no team) sees the finished canal, breathes, and is content. Hand-drawn stop-motion (8 drawings/sec, held poses).

## Consistency method
1. Fixed background plate: an empty canal with no people (FLUX.2 Klein 4B edit, Apache-2.0, local).
2. A hero reference from M-02A (the approved face) plus the plate → one "anchor" drawing per setup.
3. Each new pose is an edit of the anchor (only the pose/expression changes), with a fixed seed.
4. Remotion: a unified grade, paper grain, frame holds, sun glow, and a dissolve into the film's navy.
