# SIO Character Library (Blender 5.3)

Reusable, fully scriptable character pipeline: **MPFB 2** (body, skin, eyes, clothes) + **Rigify** (built-in, full face/IK/FK rig) + **native Hair Curves** generated by Python (no paid or third-party hair add-ons).
Built and tested on an Apple M2 Pro with 16 GB, Blender 5.3.0, MPFB build 20261010, MakeHuman system assets (CC0).

## Layout
```
sio_char/            Python package (import inside Blender)
  character.py       build("<preset>") -> Character(body, rig, parts)
  hair.py            apply_preset(ch, "<hair preset>")  -> Hair Curves + scalp cap, parented to the head bone
  materials.py       skin tint, eye tint, hair/cap shaders, stylize_toon(objects)
  rig.py             Rigify helpers: set_world, rotate_world, set_ik, hand_pose, sit
  anim.py            make_pencil/make_paper, grip, draw_strokes, look_follow, breathe, key_pose, stash (NLA)
  render.py          setup("preview"|"cinematic"|"cycles"|"toon"), still(), animation_preview()
presets/characters/  engineer_m01.json (hero), engineer_f01.json
presets/hair/        short_side_part, beard_short, long_center_part, ponytail
scripts/             poc_engineer_drawing.py (full PoC), render_preview.py (MP4 from any .blend)
tests/               PoC outputs (renders, .blend, logs)
```

## Quick start (Claude Code via Blender MCP)
```python
import sys; sys.path.insert(0, "/Users/mohammadalqurain/Documents/Remotion-MotionGraphics/blender/sio_character_library")
import sio_char
from sio_char import character, hair, rig as R, anim as A, render
ch = character.build("engineer_m01")                 # ~3 s: body + skin + clothes + Rigify (930 bones)
for h in ch.preset["hair"]: hair.apply_preset(ch, h) # ~4 s each
R.sit(ch.rig, seat_height=0.455)                     # IK legs, feet planted
R.hand_pose(ch.rig, "R", "pencil")                   # relaxed | rest_flat | pencil | point | fist
render.setup("preview")
```
Re-using a character already in the scene: `character.Character.from_scene("engineer_m01")`.
After editing library code inside a live session, drop the cached modules first:
`for m in [m for m in list(sys.modules) if m.startswith("sio_char")]: del sys.modules[m]`.

## Rules that matter
- The character faces **-Y**; his right hand is at **-X**. Rest coordinates come from MPFB shape keys (`util.rest_coords`).
- Hair is generated in the rest pose and **parented to `DEF-spine.006`** (head deform bone), so it follows any animation without simulation. Long hair follows the head rigidly (no secondary motion yet).
- Rigify arms/legs are IK by default (`IK_FK = 0`). Place controls with `rig.set_world()`; never rotate individual DEF/ORG bones.
- Writing: `anim.grip()` aligns the pencil with the proximal index phalanx and parents it to `DEF-hand.R`; `anim.draw_strokes()` solves the **hand position from the pencil tip** every frame, so the tip lies exactly on the paper and the ink curve reveals in sync.
- Head motion: `anim.look_follow()` (max 38°, 25 % neck) — lean the body with `sit(lean_deg=…)` instead of bending the neck.
- Blender 5 video output needs `image_settings.media_type = 'VIDEO'` before `file_format = 'FFMPEG'` (handled in `render.py`).
- Keep renders light on 16 GB: `preview` for checks/animation (50 %, Eevee 16 spp), `cinematic` for stills, Cycles only for single hero stills.

## Adding things
- New person: copy a JSON in `presets/characters/` (macro values 0–1, MPFB skin/clothes names from the installed system assets).
- New hairstyle: copy a JSON in `presets/hair/`; `region` = where it grows, `flow.kind` = comb direction (`side_part`, `beard`, `long_center_part`, `ponytail`), `growth` = length/volume/gravity, `density_per_cm2`, `radius`.
- New hand shape: add to `rig.HAND_POSES`.
- New action: build keys with `anim`/`rig` helpers, then `anim.stash(rig, "ACT_name")` to push it to the NLA.

## v2 (2026-11-15) — verified improvements
- Preset `engineer_m01_v2` (v1 preset and v1 PoC untouched): hair `short_side_part_v2`, beard `beard_short_v2`, Corrective Smooth bound in the rest pose, Rigify widgets moved to a hidden `SIO_rig_widgets` collection (they were render-visible in v1).

- Beard: `symmetric: true` (grow one half, mirror), `region.mustache_gap` + `region.lip_clearance` + strand trimming near the lips -> lips always visible.
- Pose: `rig.sit_natural()` (pelvis tilt, two-stage spine lean, dropped shoulders, asymmetric planted feet), `rig.arm_pole()` (elbow poles out/back/down), paper closer so elbows bend ~100°.
- Face: `rig.expression(rig, "focused")`, `anim.eyes_follow()` (Rigify `eye_common` target, lids follow), `anim.blink()/blinks()`.
- Scripts: `scripts/poc_engineer_drawing_v2.py` (reuses v1 set/lights), outputs in `tests/poc_engineer_drawing_v2/`.
- MPFB note: the body has two chained Armature modifiers ("Armature" + multi-modifier "Armature PV"); anything inserted between them breaks finger deformation — `character.py` inserts after the last one.

## Poly Haven (verified 2026-11-15)
**Live via Blender MCP** (Poly Haven = "on" in `get_addon_status`):
```python
bpy.context.scene.blendermcp_use_polyhaven = True   # per-SCENE switch: resets on every new/opened file
```
then MCP `search_assets(source="polyhaven", query=..., asset_type="textures"|"hdris"|"models")` and
`import_asset(source="polyhaven", id=..., asset_type=..., resolution="1k", apply_to=[obj])`. Afterwards:
```python
from sio_char import polyhaven as PH
PH.fix_mcp_material(bpy.data.materials["<id>"])   # MCP wires height -> real displacement (crumpled meshes); keep bump only
PH.persist()                                       # MCP packs maps into the .blend; write them to the shared cache instead
```
**Headless / no MCP** (cached once in `polyhaven_cache/`, then offline):
```python
PH.material("denim_fabric_05", res="1k")   # Principled + diff/rough/nor_gl/ao, object-space box mapping at real-world size
PH.hdri("poly_haven_studio", res="1k")     # world environment
```
Test: `Blender -b tests/polyhaven/polyhaven_test.blend -P scripts/test_polyhaven.py` (leather via MCP + denim via API, HDRI, Eevee render).
Candidates (searched, not applied to the approved character): shirt detail `stretch_poplin` (normal/roughness only), jeans `denim_fabric_05`/`denim_fabric_03`,
chair `fabric_leather_02`, desk `blue_metal_plate` (painted steel), HDRIs `poly_haven_studio`, `small_empty_room_3`, `unfinished_office`.
Skin, eyes, hair and beard stay on the MPFB / SIO shaders (Poly Haven has no human-skin materials suitable for them).
